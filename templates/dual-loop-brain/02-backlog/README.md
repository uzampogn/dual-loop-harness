# Backlog — the design loop's product, the build loop's only input

Data folder: 1 folder per item, `<NN-item-slug>/` (`spec.md` + `plan.md`),
created by `/dual-loop:design-session`. `NN` is append-only historical numbering —
never reused, never renumbered — and the branch, worktree, and build-report
folder reuse the exact same name. `BACKLOG.md` is a view generated from
beads (the source of truth) — read it, never hand-edit it.
